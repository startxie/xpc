# 🃏 斗地主游戏规则详解 (Markdown版)

## 📜 游戏简介
斗地主是中国流行的扑克游戏，通常由 **3名玩家** 参与（1名地主 vs 2名农民）。目标是通过合理叫分、出牌策略和配合，优先出完手牌者获胜。

---

## 👥 玩家角色与牌具
| 要素          | 说明                                                                 |
|---------------|----------------------------------------------------------------------|
| **玩家人数**  | 3人（固定）                                                          |
| **牌具**      | 一副54张扑克牌（含大小王）                                           |
| **角色分配**  | - **地主**：1人（获得3张底牌）<br>- **农民**：2人（联盟对抗地主）       |

---

## 🔄 游戏流程
### 1️⃣ 发牌阶段
- 洗牌后每人发 **17张牌**（共51张）
- 剩余 **3张牌** 作为「底牌」

### 2️⃣ 叫分阶段（关键决策）
> 玩家轮流选择是否叫分（1分/2分/3分），也可选择「不叫」
- ✅ **叫分最高者成为地主**（默认起始分为0）
- ⚠️ 叫分规则：
  - 只能叫比当前更高分或不叫
  - 有人叫3分时立即结束叫分
  - 无人叫分则重新发牌

### 3️⃣ 底牌分配
- 地主获得 **3张底牌**，加入手牌（共20张）
- 农民手牌保持17张

### 4️⃣ 出牌阶段（核心对抗）
- 地主先出牌，之后按 **逆时针顺序** 轮流出牌
- 每次出牌需**压过上家同类型牌型**或选择不出
- 当某方出完所有手牌时游戏结束

## 🃎 牌型与大小规则
### 基本牌型
| 牌型         | 组成要求                  | 示例                | 大小比较               |
|--------------|--------------------------|---------------------|------------------------|
| 单张         | 任意单张牌               | `♠A`                | 大王 > 小王 > 2 > A > K...3 |
| 对子         | 两张同点数牌             | `♥5 ♦5`             | 同单张比较规则         |
| 三张         | 三张同点数牌             | `♣10 ♠10 ♥10`        |                        |
| 三带一       | 三张 + 任意单张          | `(♠K ♥K ♦K) + ♣7`    | 按三张点数比较         |
| 三带一对     | 三张 + 一对              | `(♣8 ♠8 ♥8) + ♦9♦9`  |                        |
| 顺子         | ≥5张连续单牌（不可断）    | `5-6-7-8-9`          | 按最大牌点数比较       |
| 连对         | ≥3对连续对子             | `44-55-66`           |                        |
| 飞机         | ≥2组连续三张（可带翅膀） | `(333+444)+(77+88)`  | 按最小三张点数比较     |
| 炸弹         | 四张同点数牌             | `♠2 ♥2 ♣2 ♦2`        | **仅小于火箭**         |
| 火箭         | 双王（大王+小王）         | `BigJoker+SmallJoker`| **最大牌型**           |

> 💡 注：炸弹可炸任何非火箭牌型，火箭可炸一切牌型

## 🏆 胜负判定与计分
| 结果            | 得分规则                     | 说明                          |
|-----------------|----------------------------|-----------------------------|
| **地主胜**      | 农民各扣 `2×底分`           | 地主赢：`2×底分`             |
| **农民胜**      | 地主扣 `2×底分`             | 每位农民赢：`底分`           |
| **特殊奖励**    |                            |                             |
| ▶️ 春天（地主一轮出完） | 额外 ×2倍                   | 农民未出牌                    |
| ▶️ 反春（农民一轮压制） | 额外 ×2倍                   | 地主只出一手牌即被打败        |

## 🧠 进阶策略技巧
1. **叫分原则**  
   - 手牌含 **炸弹/火箭/王炸** 优先叫分
   - 大牌（2、A）数量≥4张可考虑叫分
   - 避免盲目争地主（农民易配合）

2. **出牌技巧**  
   - 首攻拆小牌试探对手
   - 保留炸弹应对关键回合
   - 农民需主动送牌给队友

3. **记牌关键**  
   - 重点记忆：2、A、王、已出炸弹
   - 推算剩余大牌位置

---

## ⚖️ 可选规则（变体）
- **癞子模式**：指定1张鬼牌作万能牌（可替代任意牌）
- **明牌规则**：开局亮牌加倍计分
- **团团转**：三家都不叫分则重新发牌

> 💬 提示：实际游戏前请确认当地规则细节！
